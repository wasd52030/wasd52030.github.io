關於本站

關於我

學店類資管畢業，快畢業時對於 GPT 一類的 LLM 快速發展感到力不從心，畢業後沒有投入開發業界，轉而從事 IT 一類偏維護職，Linux 從高中開始因為證照的緣故多少有接觸，後面做選手的時候更是天天搞，不過要到大四時藉著課程方便才額外割一塊磁區給 ubuntu。畢業後逐漸沒有在用筆電，反而組了一台桌機，想當初就把 RAM 拉到 32G，顯卡再往上捏一點，天知道現在硬體漲了多少…

扯遠了，畢業後那台桌機原本用 kubuntu 較多，windows 備用，不過後面 kubuntu 在 wayland 體驗頗差，於是就轉而使用 linus 都說讚的 fedora 了，加上工作看 windows 太多，導致後面用 windows 都有一種在上班的感覺，就逐漸將 fedora 作為 PC 的主力系統，而 windows 就放著吃灰了，LOL 那種每場不知道要批發己打雙親的遊戲還是少玩微妙XDDDDDDDDDD

敝人性質偏向肥宅，加減看看動畫、漫畫，兩年前才毅然入職迦勒底，成為 Fate/Grand Order 眾 Beast 的一員，音樂以日本歌為主，在朋友介紹 АнимациЯ – Ильич 後對於俄文/烏克蘭文的歌的興趣就來力，目前挺推 Кино(俄)、SadSvit(烏克蘭) 這兩團的，Ручной Рептилоид 這老姐個人認為更是不得不品的一環，Я хочу быть 2D 實在經典啊，但小心陷入做啥都提不起勁的虛無氛圍 na，至於歌詞我認為可有可無，FGO、怪彈等遊戲的 BGM 也是有許多佳作滴，許多近現代的中文歌聽了就渾身尷尬，就先放一邊力…

對了，敝人是堅定的 android 使用者，某水果手機或許也很好用，可惜不適合我，可操作程度太低力，Haiyaa…
